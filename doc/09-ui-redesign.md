> 2026-08-05. 본 문서는 그린필드 설계서(`01`~`08`)를 전제로, **현재 `main`에 구현된 GUI(Plan 2 부분
> 완료분)를 실제로 켜서 썼을 때 느껴지는 문제**를 진단하고 구체적으로 다시 설계한다. 원본 설계서의

| # | 사용자 보고 | 실제 원인(코드 증거) | 심각도 |
|---|---|---|---|
| P1 | "구분되어야 할 곳에 구분감이 없다" | 3개 pane이 모두 동일 배경(`bg-surface`)이고, 구분선은 `<main>`의 `border-x` 1px 단둘. 사이드바·인스펙터는 배경·그림자·구분선 全무 (`App.tsx:70,75`). 시그니처인 산화 바는 HUD에만 마운트되고 메인 창엔 없음 (`OxideBar` → `hud.tsx` 전용) | 상 |

| P3 | "활동 카드를 좌측 사이드바에서 미리 만들어둘 수 있어야 한다" | 사이드바에 **생성 진입점(＋버튼/인라인 입력)이 없음**. 빈 상태 `"활동을 추가하세요"`가 dead-end. 활동 생성은 ⌘K 자유입력 경로에만 존재 (`Sidebar.tsx:94-97`) | 상 |
| P4 | "녹화 시작을 단축키나 버튼으로 못 한다" | 메인 창에 **Record 버튼 없음**(NowCard는 stop-only, `Sidebar.tsx:70-74`). 시작은 ⌘⇧A·⌘K 모달 경로뿐. 글로벌 단축키는 ⌘⇧O(HUD 표시) **단 하나**이며 녹화 동작 없음 (`shortcuts.rs:11-13,26-28`). HUD는 display-only | 상 |
| P5 | "상단 날짜를 클릭해도 안 된다" | 코드상 캘린더 팝오버는 **구현됨**(`Header.tsx:68-70,83-107`). 그러나 팝오버 래퍼가 `data-tauri-drag-region` 중첩 내부(`Header.tsx:58,67`)라 클릭 간섭 위험 + 시각적 피드백이 미미해 인지되지 않음. **[검증 필요]** 런타임 확인 권장 | 중 |
| P6 | "전반적으로 직관적·편리하지 않다" | 모든 생성·녹화 동작이 **모달(⌘K/⌘⇧A)로 추방**되어, 화면 표면 자체는 사실상 읽기 전용. 시그니처 비주얼(산화 바) 부재 + 평평한 배경이 "어색함"의 정체 | 상 |

## 9.1 재설계 원칙(변경 없음, 재확인)

원본 `02-ux-research.md §2.6`의 7원칙과 `06-design-system.md`를 그대로 적용한다. 본 재설계는
**원칙을 바꾸는 게 아니라, 원칙이 화면에 도달하도록 구현을 끌어올리는 작업**이다. 그 중에서도
재설계를 관통하는 세 가지:

1. **표면이 곧 인터페이스다.** 생성·녹화·이동은 가능한 한 모달을 거치지 않고 타임라인/사이드바
   표면에서 직접 일어난다(Amie "instant capture", 원본 §7.1). 모달(⌘K)은 보조 경로로 내린다.
2. **시간이 주인공이다.** 타임라인(중앙)이 가장 밝고 큰 표면이고, 양 옆 pane은 한 톤 낮다. 산화 바는
   메인 창 상단에 반드시 존재한다(원본 §6.6 — 현재 누락).
3. **보이는 것이 작동한다.** 드롭 영역은 드롭 가능함을 보여주고, 녹화 가능 상태는 항상 보이는
   컨트롤로 드러난다. "숨겨진 제스처"에 동작을 맡기지 않는다.

## 9.2 정보 구조 & 레이아웃 개편 (P1)

### 현행(문제)

```
App.tsx:70  <div bg-surface>          ← 모든 pane이 같은 배경
            ├ Header (배경 없음)
            ├ aside[Sidebar]   (배경·보더 없음)
            ├ main[border-x]   (1px 보더가 유일한 구분)
            └ aside[Inspector] (배경·보더 없음)
```

세 pane이 시각적 위계없이 평평하게 나란하다. `--color-surface`(라이트=백색)와
`--color-border`(neutral-100, 거의 백색)라 1px 보더조차 거의 보이지 않는다.

### 재설계 — 표면 위계(Surface Tier) 3단

디자인 토큰에는 이미 `--color-surface / -raised / -sunken` 3단이 존재한다. **이것으로 pane을
위계화**한다(현재는 카드 내부에만 쓰임).

```
┌──────────────────────────────────────────────────────────────┐
│ ●●●   ▓▓▓▓▓▓▓▓●───────── 산화 바(메인 창 상단, 복원)   ⌘K ⚙  │ ← Header bar: surface-raised + 하단 hairline
├────────────┬─────────────────────────────┬───────────────────┤
│  Sidebar   │      Timeline (주인공)       │    Inspector      │
│  surface-  │      surface (가장 밝음)      │  surface-raised   │
│  sunken    │                              │  + 좌측 hairline  │
│  (오목)    │  ← 표면 위계로 "중심" 강조    │                   │
│  +우측hair │                              │                   │
├────────────┴─────────────────────────────┴───────────────────┤
│ 오늘 계획 5h30m · 여유           ▶ 10:28  멈춤(녹화중 표시줄) │ ← 워크로드 인라인 + 전역 녹화 트랜스포트
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 표면 토큰 | 의미 |
|---|---|---|
| Header bar | `--color-surface-raised` + 하단 `1px var(--color-border)` | 크롬. 산화 바 + 날짜 + 트랜스포트 |
| Sidebar | `--color-surface-sunken` (오목) | 보조/수납. "여기서 가져와 타임라인에 놓는다" |
| Timeline | `--color-surface` (기본, 가장 밝/크) | 주인공. 시간이 흐르는 무대 |
| Inspector | `--color-surface-raised` (볼륨) + 좌측 hairline | 요약/통계. 데이터 카드는 이미 raised라 자연스럽게 어울림 |

- 산화 바(Oxide Bar)를 **메인 창 Header에 마운트**한다(`OxideBar` 컴포넌트 재사용, 현재 HUD 전용).
  `onClickMinute` → 해당 분으로 타임라인 스크롤(원본 §6.6 요구사항). 이 한 줄로 제품 정체성 복원.
- Header 자체에 배경을 주어 "크롬 vs 본문" 구분을 만든다(현재 Header는 투명).

## 9.3 핵심 인터랙션 재설계

### 9.3.1 타임라인에서 직접 만들기 — 클릭 & 드래그-투-크리에이트 (P2)

> 원본 §7.1이 명시했으나 미구현. 사용자가 "원래 됐었는데"라고 기억하는 핵심 기능.

**A. 빈 슬롯 클릭 → 인라인 빠른 추가 (click-to-create)**

타임라인의 빈 시간대를 클릭하면, **그 자리에** 클릭한 시각이 시작으로 채워진 30분 초안 블록이
인라인으로 나타난다(모달 아님). 블록 내부에 포커스된 입력창:

```
09:00 │
      │ ┌─────────────────────────┐
      │ │ ▎ ▏ 집중 작업             │   ← 입력 포커스, @색상 힌트
      │ │   09:00–09:30   ▶녹화 ⌫  │   ← 엔터=생성, Esc=취소
      │ └─────────────────────────┘
10:00 │
```

- `Enter` → 제목 그대로 활동이 없으면 `createActivity` 후 `createPlan`, 있으면 매칭 활동으로
  `createPlan`. 기존 `CommandPalette.parseInput`(@시간 힌트) 로직을 그대로 재사용.
- `@색` 토큰으로 카테고리 즉시 지정 가능(기존 `@HH:MM` 파서 확장).
- 구현 위치: `RecordTimeline.tsx`의 타임라인 droppable 영역에 `onClick` 추가 → 클릭 Y좌표 →
  분 변환(`pxPerMin` 역산) → 5분 스냅(`dnd.tsx:96` `snapMinute` 재사용) → 초안 상태(state).

**B. 타임라인 표면 직접 드래그 → 블록 생성 (drag-to-create)**

빈 공간에서 누른 채 드래그하면 고무줄(rubber-band)로 블록을 그린다. 놓으면 그 시간 범위의 초안
블록이 나타나고(위 A와 동일한 인라인 입력), 엔터로 확정. 이것이 "드래그해서 계획 생성"의 정석
(Google Calendar식).

- `onPointerDown`(빈 영역) → 드래그 거리 8px 이상 시 생성 모드 진입 → `onPointerMove`로 고무줄
  표시 → `onPointerUp`으로 확정. 이미 `PlanCard` 리사이즈(`RecordTimeline.tsx:199-222`)가 같은
  패턴을 쓰므로 일관됨.
- 사이드바 드래그(dnd-kit)와 충돌하지 않음: 사이드바 드래그는 `active.data.kind==="activity"`이고,
  표면 드래그는 네이티브 포인터 제스처이므로 별개 레이어.

**C. 사이드바→타임라인 드래그: 드롭 피드백 추가 (기존 동작 보강)**

현재 `dnd.tsx:42-72`에서 실제로 `createPlan`이 호출되지만, **드래그 중 타임라인이 반응하지 않아**
"안 된다"고 인식된다. `useDroppable`의 `isOver`를 타임라인 영역에 연결해:

- 드래그 중 해당 lane 전체에 얇은 강조 링(`ring-interactive-primary/40`).
- 드롭 예정 위치에 5분 스냅된 시각 라벨이 붙은 **고스트 블록** 표시(`computeDropMinute` 값 사용).
- `PlanCard`는 이미 `isOver` 링을 가짐(`RecordTimeline.tsx:173`) — 타임라인 본체만 동일 처리 누락.

### 9.3.2 사이드바에서 활동 카드 만들기 (P3)

`ActivityLibrary` 헤더(`Sidebar.tsx:90-93`)의 `"드래그 → 배치"` 옆에 **`＋` 버튼** 추가:

```
┌────────────────────────────┐
│ 활동 · 카드        ＋ 추가   │
├────────────────────────────┤
│ ● 집중 작업   주 10h ▎▎▎▏  │
│ ● 운동        주 3h  ▎▏    │
│ ┌＋ 새 활동 이름________┐  │  ← ＋ 클릭 시 인라인 입력 행
│ │  카테고리 [업무▾]  엔터│  │
│ └───────────────────────┘  │
└────────────────────────────┘
```

- `＋` → 인라인 입력 행 노출 → 이름 + 카테고리 선택 + `Enter` → `useCreateActivity`.
- 빈 상태(`Sidebar.tsx:94-97`)를 dead-end 텍스트에서 **CTA 버튼**으로 변경:
  `＋ 첫 활동 만들기`.
- 카드 hover 시 우측에 `▶` 빠른 녹화 시작 버튼 노출(9.3.3과 연계).

### 9.3.3 녹화 시작 — 보이는 컨트롤 + 글로벌 단축키 (P4)

**현행:** 시작은 ⌘⇧A/⌘K 모달뿐. NowCard는 stop-only. 글로벌 단축키는 HUD 표시 단 하나.

**재설계 — 세 가지 상호보완 진입점:**

1. **Header 트랜스포트(항상 보임):** 산화 바 아래 얇은 트랜스포트 행. 비활성 시
   `▶ 녹화 시작`(클릭 → 직전 활동 즉시 시작, 또는 작은 인라인 피커). 녹화 중 시
   `■ 멈춤 · 10:28 · 집중 작업`(라이브 타이머). NowCard는 이 트랜스포트의 상세/사이드바 미러.
2. **NowCard 활성 CTA:** 비활성 NowCard(`Sidebar.tsx:42-53`)의 수동 텍스트를
   `▶ 녹화 시작` 버튼으로 교체. "⌘⇧A로 전환"은 보조 힌트로 하단 유지.
3. **글로벌 단축키 추가(단축키로 녹화):**
   - `CmdOrCtrl+Shift+R`(또는 `⌘⇧Space`) → **퀵 토글 녹화**: 녹화 중이면 멈춤, 아니면 직전 활동
     즉시 시작. `shortcuts.rs`에 핸들러 추가 → `start_record`/`stop_record` 명령 호출.
   - `⌘⇧O` → HUD(유지). 단, **HUD를 actionable로** 개편(아래).

**HUD 개편(actionable):** 현재 HUD는 display-only. 산화 바 클릭 jump를 연결하고(`onClickMinute`
전달, 현재 `hud.tsx`에서 미전달), 하단에 `▶/■` 녹화 토글 버튼 추가. "지금 할일"만 보여주고 끝나는
수동 디스플레이에서 → "지금 할일을 보고 한 번에 녹화까지"로 승격.

### 9.3.4 날짜 네비게이션 (P5)

- 코드상 팝오버는 동작하나 **[검증 필요]**: 래퍼가 `data-tauri-drag-region` 중첩. 가장 확실한
  해법 — **팝오버를 body 레벨 포털(portal)로 렌더**하여 drag-region 영향권에서 완전히 이탈.
- 시각적 단서 보강: 날짜 텍스트 옆 `⌄` 캐럿을 더 보이게(`text-text-muted`, 현행
  `text-text-subtle text-[10px]`), 호버 시 날짜 전체에 배경 강조. "여기를 누르면 달이 뜬다"는
  affordance를 명시.
- 주간 스트립(week strip, `Header.tsx:139-180`)은 잘 동작하므로 유지.

## 9.4 단축키 체계 재정비 (P4 연계)

원본 §7.10 표에 대비해, 현재는 글로벌이 ⌘⇧O 하나뿐. **녹화 중심 앱인데 녹화 단축키가 없다**는 것이
핵심 결함. 재정비:

| 단축키 | 동작 | 범위 | 상태 |
|---|---|---|---|
| `⌘⇧O` | HUD 표시 | 전역 | 구현됨(유지) |
| **`⌘⇧R`** | **퀵 토글 녹화(시작/멈춤)** | **전역** | **신규(추가)** |
| `⌘⇧A` | 활동 스위처(녹화 전환) | 앱 내 | 구현됨(유지) |
| `⌘K` | 커맨드 팔레트 / 빠른 추가 | 앱 내 | 구현됨(모달→보조로 격하) |
| `⌘N` | 오늘 날짜 빠른 추가 | 앱 내 | 구현됨 |
| `T` / `←` `→` | 오늘 / 전후일 | Day | 구현됨 |
| `Enter`(블록) | 블록에서 녹화 시작/토글 | 타임라인 | **신규(표면 인터랙션과 연동)** |

`Preferences.tsx:24-31,157-165`의 단축키 참조 표가 현재 실제 바인딩과 불일치/불완전하므로 함께 갱신.

## 9.5 구현 로드맵(우선순위)

각 단계는 독립적으로 기능 가치를 갖는다. P1(시각) + P4(녹화)가 체감 개선의 대부분을 차지하므로
1순위. 수용 기준: 각 단계 후 `bun run build` + vitest + `cargo build --workspace` green.

### Phase R1 — 시각 위계 + 녹화 진입점 + 사이드바 생성 (1순위, 체감 최대)
- pane 표면 위계화: Sidebar `surface-sunken` + 우측 hairline, Inspector `surface-raised` + 좌측
  hairline, Header `surface-raised` + 하단 hairline (`App.tsx`, `Sidebar.tsx`, `Inspector.tsx`).
- 산화 바를 Header에 마운트 + `onClickMinute` 스크롤 연결 (`OxideBar` → `Header`).
- Header 트랜스포트(▶/■ 녹화) + NowCard 비활성 CTA 버튼.
- 사이드바 `＋ 활동` 인라인 생성 + 빈 상태 CTA.
- 수용: 3개 pane이 시각적으로 구분됨, 클릭 한 번에 녹화 시작 가능, 사이드바에서 활동 생성 가능.

### Phase R2 — 타임라인 표면 직접 생성 (사용자 회귀 요구)
- 빈 슬롯 클릭 → 인라인 빠른 추가(초안 블록 + 입력).
- 표면 드래그 → 고무줄 블록 생성.
- 사이드바 드래그 드롭 피드백(타임라인 `isOver` 강조 + 고스트 블록 + 스냅 시각 라벨).
- 수용: 마우스만으로 타임라인에 계획 생성 가능, 드롭이 즉시 보임.

### Phase R3 — 단축키 + 날짜 + HUD actionable
- 글로벌 `⌘⇧R` 퀵 토글 녹화 (`shortcuts.rs` 핸들러 추가).
- 날짜 팝오버 포털화(drag-region 이탈) + affordance 보강 + **[런타임 검증]**.
- HUD actionable화(산화 바 jump + ▶/■ 토글).
- Preferences 단축키 표 갱신.
- 수용: 키보드만으로 녹화 시작/멈춤, 날짜 클릭이 확실히 동작.

### Phase R4 — 정리
- 미사용 `NowLine.tsx` 제거(타임라인은 inline now-line 사용 중).
- HUD 산화 바 `onClickMinute` dead-code 해소(R3에서 연결).
- 미사용 `resolveActivity` 명령 프론트엔드 연결 여부 결정.
- 레거시 뷰(Backlog/Week) — 현재 메인에 뷰 스위처가 아예 없음. 백로그(날짜 없는 할일) 진입점을
  사이드바 하단 또는 Header 탭으로 복원할지 결정(원본 §7.2). [별도 의사결정 필요]
