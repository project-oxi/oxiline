A · 두 Pane 분할계획 ↔ 실제, 동기화된 시간축

계획 pane(좌)엔 OR 선택지를, 실제 pane(우)엔 기록된 단일 흐름을. 같은 시간축으로 나란히 비교 — "09:00엔 코딩/독서 중 택1이었고, 코딩을 했네." 비교가 가장 선명하지만 폭을 두 쪽으로 쓴다.

B · 단일 타임라인 + 토글계획 / 실제 / 둘 다

하나의 캔버스. [둘 다] 모면 계획 선택지(점선 ghost) 위에 실제 기록(실선)이 올라간다 — 코딩이 "선택지였고 + 실제로 했다"가 한 자리에. 절약되는 폭 대신 모드 전환 기억 부담. "둘 다"가 기본값이면 부담 감소.

C · 선택 카드OR가 구조 — 선택지 + 결과가 한 카드에

토글·분할 없이, 시간대 자체가 '선택(OR) 카드'. 선택지를 나열하고 실제로 한 것을 표시. "9시엔 코딩·독서 중 코딩을 1h30 했고, 11시엔 코딩·글쓰기·운동 중 코딩 하는 중." OR 의미가 가장 정직하게 드러나고, 과거/미래가 같은 컴포넌트로 자연스럽게 이어진다.
